Methodology
What this is: a directed graph linking one event's extracted effect text to a later event's extracted cause text (gold_cause / gold_effect, from the same corpus the Event Risk Terminal uses), within a 120-day window.

What scores the links today: TF-IDF cosine similarity — lexical overlap, not semantic causal reasoning. Most event pairs score zero; roughly 3 in 10 events have at least one kept link.

What replaces it: a BART-based causal model, trained/run locally (outside this sandbox — no network access here to even download a transformer). It would re-score the same effect→cause pairs with real entailment/causal understanding instead of word overlap, plugging into the same events/edges/transition_table schema this page already reads.

Read every number here as: "historically, this is the event type that followed" — not a price move, not a probability of a specific dollar outcome.
